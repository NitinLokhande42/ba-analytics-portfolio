# Business Analyst & Analytics Portfolio — Nitin Lokhande

Eleven end-to-end case studies from my work as a **Business Analyst / Data Analyst** across Genpact, Neutrino and Cipla.
Each project folder shows the full BA lifecycle: the business problem, requirements artefacts (BRD, user stories,
KPI dictionary, UAT plan), the data model and SQL, and a working analytical prototype in Python.

> **Data disclaimer:** All datasets in this repository are **synthetic**, generated by the scripts in each `data/` folder.
> No client, patient or employer data is included. Numbers in the generated outputs are illustrative and calibrated to
> resemble the shape of the real problem; the **Impact** figures quoted are the outcomes reported on the actual engagements.

## How each project is organised

```
NN-project-name/
├── README.md            # Problem, my BA role, approach, results, impact
├── docs/                # BRD, user stories, KPI dictionary, UAT / test plan, process maps
├── sql/                 # Snowflake-style DDL and analytical queries
├── data/generate_data.py# Synthetic data generator (reproducible, seeded)
└── src/                 # Analytical prototype (model, simulator, rules engine…)
```

## Quick start

```bash
git clone https://github.com/NitinLokhande42/ba-analytics-portfolio.git
cd ba-analytics-portfolio
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run_all.py            # generates data and runs every project's analysis
# or run one project
python 01-marketing-mix-model/data/generate_data.py
python 01-marketing-mix-model/src/mmm_model.py
```

Outputs are written to each project's `output/` folder (git-ignored).

## Skills demonstrated

**Business analysis:** requirement workshops, stakeholder interviews, BRD/FRD, user stories with acceptance criteria,
KPI dictionaries, as-is/to-be process mapping, gap analysis, UAT planning and execution, parallel runs, change management.

**Analytics:** Bayesian regression, adstock/saturation curves, budget optimisation, time-series forecasting, clustering,
gradient boosting, A/B testing & power analysis, uplift modelling, Monte Carlo NPV, linear assignment, NL-to-SQL evaluation.

**Tools:** SQL (Snowflake), Python (pandas, scikit-learn, SciPy), Power BI (DAX, RLS), Salesforce, AWS, JIRA,
Power Apps / Power Automate, SharePoint.
