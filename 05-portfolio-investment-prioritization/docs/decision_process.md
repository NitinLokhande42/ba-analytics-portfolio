# Portfolio Decision Process

```
Intake form ──► Gate 1: Screening (1 day) ──► Gate 2: Full evaluation (3 days) ──► Gate 3: Portfolio committee (1 day)
```

| Gate | Input | Activity | Decision maker | Output |
|---|---|---|---|---|
| Intake | 1-page form: product, market, rationale | BA checks completeness | Portfolio office | Accepted / returned |
| Gate 1 | Intake + rough sizing | Strategic fit score; kill obvious misfits | Head of Portfolio | Proceed / stop |
| Gate 2 | Assumption ranges from each function | Monte Carlo NPV + scorecard | Cross-functional review | Scored project |
| Gate 3 | Ranked portfolio within capex budget | Leadership reviews dashboard; trade-offs | Portfolio committee (CEO, CFO, CSO, COO) | Funded / deferred / stopped |

## RACI
| Activity | R&D | Marketing | Mfg | Finance | BA / Portfolio office |
|---|---|---|---|---|---|
| Assumption ranges | R | R | R | A | C |
| NPV model run | C | C | C | A | R |
| Strategic scoring | R | R | R | C | A |
| Dashboard & pack | I | I | I | C | R/A |
| Final decision | C | C | C | C | I (committee = A) |

**Cycle time:** 6 weeks → 1 week, because assumptions are pre-agreed and the model is standard.
